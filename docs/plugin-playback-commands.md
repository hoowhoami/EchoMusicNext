# 皮肤设置关闭与呈现生命周期

`EchoPluginViewContext.closeSkinSettings()` 或 `command("closeSkinSettings", {})` 返回真实 `EchoPluginOperation`，仅作用于当前活动的皮肤设置呈现。命令在 GUI 队列执行前校验作用域及账号世代；退出或撤销后不执行迟到请求。

关闭操作先确认成功，再向宿主请求关闭设置，避免设置正文销毁自己的呈现 scope 时把已经执行的关闭误报为取消。`aboutToClose` 在呈现撤销前同步通知，插件应撤销动画、计时器、订阅及待交付结果；后台任务仍须等真实退出后才算排空。

播放、队列、音量和睡眠定时保持主线接口与行为。只读 A/B 转场数据用于歌词和视觉，不提供播放来源选择或恢复命令。

验证入口为 `tests/qt/PluginViewCommandsTest.cpp`：活动呈现关闭、失效呈现拒绝，以及自身关闭导致退休的完成顺序。精简后的实际构建结果由本次验证记录另行报告，不沿用旧控制扩展的测试数量。
